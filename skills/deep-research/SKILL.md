# Deep Research (IterResearch pattern)

Глубокий ресёрч для случаев когда обычного web_search недостаточно: анализ конкурентов, маркетинговые исследования, технические сравнения, due diligence. По мотивам Odysseus `src/deep_research.py` (DeepResearcher, 929 строк).

## Когда использовать

- Нужен **структурированный отчёт** на 2+ страницы, а не 3-5 ссылок
- Тема требует **многораундового поиска** (новые запросы на основе найденного)
- Важны **источники** — какие именно сайты/документы легли в выводы
- Задача: "исследуй X", "сделай обзор Y", "сравни A и B", "найди все про Z"

## Когда НЕ использовать

- Простой факт-чекинг → `web_search`
- Один конкретный URL → `extract_content_from_websites`
- Быстрый листинг чего-то → `web_search` с site: оператором

## Паттерн IterResearch (6 фаз)

### Фаза 1: PLAN
Сформулируй research plan в 2-5 пунктов:
- Какие подвопросы нужно раскрыть
- Какие источники вероятно релевантны
- Критерии остановки (что считать "достаточно")

### Фаза 2: QUERY
Генерируй 2-4 поисковых запроса на раунд. На первом раунде — общие, дальше сужай на основе уже найденного. Запросы должны быть разные (не дубликаты).

### Фаза 3: SEARCH
`mcp_matrix_batch_web_search(queries=[...])` — собирай URL топ-результатов. Если <5 валидных результатов, перефразируй.

### Фаза 4: EXTRACT
`mcp_matrix_extract_content_from_websites` на топ-5 URL каждого раунда. Фильтруй — если страница не по теме, выкидывай. Извлекай **только релевантные** абзацы (длинный prompt с конкретным вопросом).

### Фаза 5: SYNTHESIZE
Обнови `evolving_report`:
- Добавь новые findings (bullet points с source URL)
- Реорганизуй если структура уже не подходит
- Следи за объёмом (не раздувай, цель — 1500-3000 слов)
- Выделяй **противоречия** между источниками

### Фаза 6: DECIDE
Реши: continue (ещё раунд) или stop. Продолжай если:
- Есть подвопросы без ответа
- Нашлись новые подтемы
- Не хватает глубины по 1-2 пунктам

Стоп если: 3+ раунда подряд без нового материала, все пункты плана закрыты, или достигнут лимит (см. ниже).

## Лимиты

- **max_rounds**: 5 (по умолчанию), максимум 8
- **min_rounds**: 2 (для качества)
- **max_empty_rounds**: 2 (подряд без нового)
- **max_time**: 10 мин на всё исследование
- **urls_per_round**: 3-5 топовых URL
- **synthesis_window**: последние 10 раундов для контекста синтеза

## Структура финального отчёта

```
# <Title>

## Резюме (3-5 предложений)

## Методология
- N раундов, M источников
- Ключевые запросы

## 1. <Раздел 1>
- finding 1 [source](url)
- finding 2 [source](url)
- ...

## 2. <Раздел 2>
...

## Противоречия и caveats
- <что расходится между источниками>

## Источники
1. <title> — <url>
2. ...
```

## Как запускать

1. Пользователь просит "исследуй X" / "сделай обзор Y"
2. Загрузи этот skill (`skill_view(name='deep-research')`)
3. Скажи пользователю план: "Начну с N раундов по подвопросам: ..."
4. Используй `mcp_matrix_batch_web_search` + `mcp_matrix_extract_content_from_websites`
5. После каждого раунда — явно обновляй evolving_report
6. Когда решил stop — отдай финальный отчёт
7. Сохрани в Obsidian: `/root/Documents/Obsidian/Wize/06 Archive/research-<topic>-<date>.md`

## Pitfalls

- **Не делай 8 раундов тупо** — после 2-3 пустых раундов стоп
- **Не копируй весь текст страниц** — извлекай только релевантные абзацы через промпт
- **Следи за источниками** — каждый finding должен иметь URL, иначе это уже не ресёрч а эссе
- **Противоречия — не баг, а фича** — если источники расходятся, отметь это явно
- **Russian content** — для русскоязычных тем используй кириллические запросы, не транслит

## Шаблон промпта для extract

```
"Извлеки из этой страницы только информацию по теме: <конкретный вопрос>. 
Игнорируй меню, рекламу, footer. Верни bullet points с короткими цитатами 
и цифрами. Если тема не освещена — так и скажи."
```

## Пример

Запрос: "Исследуй рынок доставки еды в Дубае 2026"

Раунд 1: общий план → 3 запроса про размер рынка, игроков, тренды → top-5 URL → извлекли
Раунд 2: сужаем — "Talabat vs Deliveroo market share 2026" + "cloud kitchens Dubai" → ещё URL
Раунд 3: финализируем — "regulations food delivery UAE 2026" → последние факты
Стоп: 3 раунда, 12 источников, отчёт готов.
