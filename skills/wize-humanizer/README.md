# Wize Humanizer

> **Based on [blader/humanizer](https://github.com/blader/humanizer) (MIT, 2.11.2)**
> Русскоязычная адаптация для Wize Agency / Hermes bot. Автор оригинала: blader.

Переписывает текст, звучащий как ИИ, чтобы он читался как написанный человеком. 35 базовых паттернов из Wikipedia ["Signs of AI writing"](https://en.wikipedia.org/wiki/Wikipedia:Signs_of_AI_writing) + 10 русских специфичных (канцеляризмы, отглагольные сущ., заимствования, вводные).

## Зачем

ChatGPT/Claude/Gemini выдают текст, который *узнаваемо* пахнет ИИ:
- "Ключевой/поворотный момент"
- "В современном мире"
- "является ключевым"
- Тройки параллельных конструкций
- Пустые "Таким образом" в конце

Wize Humanizer ловит это и переписывает.

## Использование в Hermes

Скилл автоматически доступен если подключён к `~/.hermes/skills/`. Просто дай задание:

```
"Гуманизируй этот текст: <вставь текст>"
```

## Алгоритм

1. Найти AI-паттерны в тексте
2. Сохранить смысл
3. Не выдумывать факты
4. Поймать голос автора (если есть образец)
5. Двухэтапная проверка (черновик → прогон по списку → финал)
6. Показать отчёт что исправлено

## Что внутри
