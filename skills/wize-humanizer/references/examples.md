# Примеры до/после

## Пример 1: маркетинговый текст

**Было:**
> В современном мире цифровых технологий инновационные решения играют ключевую роль в развитии бизнеса. Многие эксперты отмечают, что данные платформы являются прорывом в своей отрасли. Безусловно, будущее выглядит светлым, и компания готова к новым вызовам. Благодаря использованию передовых технологий, мы обеспечиваем комплексный подход к решению задач клиентов.

**Стало:**
> Платформы изменили работу. Тесты в трёх компаниях показали рост конверсии на 30%. Команда продолжит развивать продукт.

**Что убрано:**
- "В современном мире цифровых технологий" — пустой контекст
- "Играют ключевую роль" — канцелярит
- "Многие эксперты отмечают" — расплывчатый источник
- "Являются прорывом" — раздутая важность
- "Безусловно" — паразит
- "Будущее выглядит светлым" — пустой позитив
- "Комплексный подход" — маркетинговая вода
- "Обеспечиваем" — канцелярит
- "Использование передовых технологий" — замена простого "применяем"

## Пример 2: техническая статья

**Было:**
> Архитектура данного решения представляет собой микросервисную систему, основанную на принципах SOLID. Осуществляется контроль над всеми аспектами работы. Необходимо отметить, что данный подход является ключевым для обеспечения стабильности. В заключение хочется отметить, что будущее за микросервисами.

**Стало:**
> Решение — набор микросервисов с принципами SOLID. Контроль покрывает все основные сценарии. Это даёт стабильность в продакшене.

**Что убрано:**
- "Представляет собой" — лишнее
- "Данного" — лишнее слово
- "Осуществляется контроль над всеми аспектами" → "Контроль покрывает основные сценарии"
- "Необходимо отметить" → "Это"
- "Является ключевым для обеспечения" → "даёт"
- "В заключение хочется отметить" → удалено

## Пример 3: пресс-релиз

**Было:**
> Компания "Ромашка" представила инновационное решение в сфере финтеха. По мнению экспертов, продукт является прорывом на рынке. В современных реалиях, когда цифровизация набирает обороты, такие решения особенно актуальны. Компания планирует расширять присутствие на рынке.

**Стало:**
> "Ромашка" выпустила новый финтех-продукт. Аналитик Тинькофф-банка назвал его "самой быстрой интеграцией с API за последние два года". До конца года компания добавит ещё 3 банка-партнёра.

**Что убрано:**
- "Инновационное решение" → "новый продукт"
- "По мнению экспертов" → конкретный эксперт + цитата
- "Является прорывом" → цитата с конкретикой
- "В современных реалиях, когда цифровизация набирает обороты" → удалено (вода)
- "Особенно актуальны" → удалено
- "Планирует расширять присутствие" → "добавит ещё 3 банка"

## Пример 4: пост в соцсетях

**Было:**
> Друзья, сегодня хочу поделиться с вами важной новостью! 🚀 Является большим счастьем сообщить вам, что мы запустили новый проект. Безусловно, это стало возможным благодаря вашей поддержке. Спасибо вам огромное! 🙏

**Стало:**
> Мы запустились. Спасибо всем, кто помогал — без вас бы не вышло.

**Что убрано:**
- "Друзья" + "!" → без формальностей
- "Хочу поделиться важной новостью" → "Мы запустились"
- "Является большим счастьем сообщить" → удалено
- "Безусловно" → удалено
- "Благодаря вашей поддержке" → "кто помогал"
- "Огромное" → удалено
- "🚀" и "🙏" → удалены
